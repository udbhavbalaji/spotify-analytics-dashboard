
# spotify-analytics

## Core features of the MVP:

1. Spotify OAuth Login - to access the user's listening data [!!!]
2. User's listening history - display the user's previous songs played [!!]
  - Allow user's to search by name of artist,track,album and filter by genre
3. Audio features visualizer - using radar chart, allow comparison of multiple tracks together [!!]
4. Genre & Artist Distribution - Top artists/genres/tracks shown in bar/pie chart with options for grouping over time (last month, all-time, last week, etc.) [!!!]
5. Daily listening activity tracker - using line chart, chart out the user's listening activity during the day, allowing for comparison compared to daily, weekly, monthly, yearly, all-time averages [!!!]
6. Very authentic looking dashboard UI with all the charts - has to be on-brand with spotify and be responsive.


Nice-to-have features [lowest priority]:

1. Niched playlist generator - time based inputs for recommendations (option to use audio features to help improve/guide recommendations)
2. Allow social features - users can compare listening habits and certain comparative trends with friends
3. Weekly listening snapshot - via email/notification
